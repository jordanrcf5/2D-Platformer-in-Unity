# Unity 2D Platformer (First Project)

This is my **first complete Unity game project**, built using C# and Unity by following a guided tutorial series.  
The goal of this project was to learn **core Unity workflows**, **clean and simple game architecture**, and to complete a fully playable game from start to finish.

## Overview

This project is a 2D platformer focused on clean, readable, and beginner-friendly code while still implementing a wide range of common platformer mechanics.  
I followed the tutorial step by step, committed consistently to GitHub, and used this project to understand how different gameplay systems work together in Unity.

## Features

- Player movement
- Tilemaps & platforms
- Jumping & double jumps
- Gravity effects
- Wall jumps & wall slides
- Animations (Idle, Run, Jump, Fall, Wall Slide)
- Particle effects (jump & direction change)
- Camera bounds confinement
- Collectible items (gems)
- Progress bar (slider)
- One-way platforms (jump up / drop down)
- Level loading
- Hold-button mechanics
- Enemy AI
- Object spawner on valid platform tiles
- Player health bar
- Game over screen
- Shooting projectiles toward mouse position
- Loot tables
- Health pickup items

## Tech Stack

- **Engine:** Unity
- **Language:** C#
